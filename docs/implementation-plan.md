# 实现与验证计划

依据已确认的 [设计文档](superpowers/specs/2026-11-17-campus-network-design.md)。

1. 实现配置、密钥环、NetworkManager 封装、联网探测和表单认证。
2. 实现可测试的串行状态机：稳定等待、连接失败冷却、认证退避、暂停。
3. 实现 GTK 单实例应用：网络配置、认证配置、运行选项、状态与日志。
4. 添加桌面入口、用户自动启动和 `.deb` 构建脚本。
5. 通过模拟 NetworkManager 和本地 HTTP 服务验证关键流程；运行真实只读扫描和 GUI 冒烟检查。
6. 检查安装包结构、依赖和隔离解包运行，记录无法执行的实机认证验收项。
7. 检查差异并用中文提交说明提交，推送到 `main`。

## 0.2.0 协议适配补充

- 根据实际 GET 请求实现重庆大学 Dr.COM 参数与 JSONP 响应解析。
- 每次认证从所选无线网卡读取 IPv4，自动拼接可配置账号前缀，不保存真实抓包中的地址或密码。
- 界面增加自动识别/重庆大学/普通表单模式，保留旧版配置兼容。
- 通过本地服务和 GUI 验证后构建安装包、提交推送；实际登录由用户从源码运行后现场测试。

## 界面方向

采用网络控制台式布局：左侧页面导航，右侧配置，顶部持续显示运行状态。网络页用“优先 → 备用”的连线式顺序卡片表达真实切换规则。

- 颜色：纸白 `#F7F9FC`、深蓝 `#17324D`、链路蓝 `#246BCE`、在线青 `#137C70`、边框灰 `#DCE4ED`、告警棕 `#9A5B18`。
- 标题使用系统无衬线粗体，正文使用系统中文无衬线字体，网络名称和运行日志使用等宽字体。
- 普通控件保留 GTK 的键盘操作、焦点和缩放支持，不加入装饰性动效。
- “顺序卡片”仅用于两个确实存在优先关系的网络，其余设置保持朴素表单，避免把所有内容都做成仪表盘。
